## 2️⃣ 开发环境配置

### 第一步：注册云 Mac

```
1. 访问 MacinCloud 官网
2. 注册账号
3. 选择 Pay-As-You-Go 套餐
4. 充值 $10 (可以用 10 小时+)
5. 下载远程桌面客户端
6. 连接云 Mac
```

### 第二步：云 Mac 内配置

```
1. 打开 App Store
2. 登录 Apple ID (免费)
3. 下载 Xcode (最新)
4. 安装命令行工具
5. 配置 Git
```

### 第三步：本地准备

```
1. 安装 VS Code (代码编辑)
2. 安装 Git
3. 注册 GitHub 账号
4. 安装远程桌面软件
```
