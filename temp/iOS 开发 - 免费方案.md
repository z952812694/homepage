## 方案 B: 黑苹果 (完全免费，但有风险)

### 什么是黑苹果

在普通 PC 上安装 macOS 系统

### 优点

- ✅ 完全免费
- ✅ 性能最好
- ✅ 可以长期使用

### 缺点

- ⚠️ 安装复杂 (需要技术)
- ⚠️ 可能不稳定
- ⚠️ 硬件兼容性要求高
- ⚠️ 法律灰色地带

### 硬件要求

| 组件 | 要求 |
|------|------|
| CPU | Intel (推荐) / AMD (困难) |
| 主板 | 支持 UEFI |
| 显卡 | AMD (免驱) / NVIDIA (困难) |
| 网卡 | 需要兼容型号 |
| 硬盘 | 任意 SSD |

### 安装教程

1. **Dortania 指南** (最权威)
   - https://dortania.github.io/OpenCore-Install-Guide/
   
2. **B 站教程** (中文)
   - 搜索 "黑苹果安装教程"

3. **镜像下载**
   - https://www.insanelymac.com/

```
⚠️ 如果主人是技术小白 → 不推荐
✅ 如果主人喜欢折腾 → 可以试试
```
