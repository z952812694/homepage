## 🛠️ 完整设置流程

### 第一步：准备 Apple ID

```
1. 如果没有 Apple ID，注册一个
   - https://appleid.apple.com
   
2. 在 iPhone 14 上登录
   - 设置 → 登录 Apple ID
   
3. 开启开发者模式 (iOS 16+)
   - 设置 → 隐私与安全 → 开发者模式 → 开启
   - 需要重启手机
```

### 第二步：云 Mac 试用

```
1. 注册 MacinCloud
   - https://www.macincloud.com
   - 首次注册送 1 小时免费
   
2. 下载远程桌面
   - Microsoft Remote Desktop
   
3. 连接云 Mac
```

### 第三步：云 Mac 内配置

```
1. 打开 App Store
2. 下载 Xcode (免费)
3. 打开 Xcode
4. 登录 Apple ID
   - Xcode → Settings → Accounts
   - 添加 Apple ID
```

### 第四步：连接 iPhone 14

```
方法 1: USB 连接 (推荐)
1. 云 Mac 支持 USB 重定向
2. 用数据线连接 iPhone
3. Xcode 识别设备

方法 2: 无线连接
1. 同一 WiFi 网络
2. Xcode → Window → Devices
3. 添加设备
```

### 第五步：创建第一个 App

```
1. Xcode → File → New → Project
2. 选择 "App"
3. 界面：SwiftUI
4. 运行目标选择 iPhone 14
5. 点击运行 (Cmd+R)
6. 信任开发者 (iPhone 上)
   - 设置 → 通用 → VPN 与设备管理
   - 信任 Apple ID
```

## 📋 详细设置步骤

### iPhone 14 设置

```
1. 更新到最新 iOS
   设置 → 通用 → 软件更新

2. 开启开发者模式
   设置 → 隐私与安全 → 开发者模式
   (如果没有，先连接 Xcode 会自动出现)

3. 信任电脑
   连接云 Mac 时，iPhone 会提示
   点击"信任"
```

### Xcode 配置

```
1. 打开 Xcode
2. Settings → Accounts
3. 添加 Apple ID (免费)
4. 查看签名团队
   应该显示个人 Apple ID
```

### 信任开发者

```
第一次安装 App 后：

1. iPhone 设置 → 通用
2. VPN 与设备管理
3. 找到 Apple ID
4. 点击"信任"
5. 确认信任
```
