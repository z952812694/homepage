## 🎨 进阶技巧

### 角色一致性

```
问题：多次生成角色长得不一样

解决:
1. 使用同一张参考图
2. 固定提示词描述
3. 使用"角色锁"功能 (部分工具有)
4. 训练专属模型 (进阶)
```

### 动作控制

```
让动作更自然:
1. 描述具体动作
2. 使用"缓慢/流畅"等词
3. 避免复杂动作
4. 时长控制在 5 秒内
```

### 提高质量

```
1. 提示词详细具体
2. 使用高质量关键词
3. 参考图辅助
4. 多次生成选最佳
5. 后期调色增强
```
