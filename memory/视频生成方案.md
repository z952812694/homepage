## 💻 程序生成视频方案

### 方案 A: Python + MoviePy

**适合**:  programmatically 生成视频

```python
# 安装
pip install moviepy

# 示例代码
from moviepy.editor import *

# 创建文字剪辑
txt_clip = TextClip("主人好！🌸", fontsize=70, color='white')
txt_clip = txt_clip.set_pos('center').set_duration(5)

# 创建背景
color_clip = ColorClip(size=(1920, 1080), color=(60, 60, 60))
color_clip = color_clip.set_duration(5)

# 合成
video = CompositeVideoClip([color_clip, txt_clip])
video.write_videofile("output.mp4", fps=24)
```

**功能**:
- ✅ 文字生成视频
- ✅ 图片合成视频
- ✅ 视频剪辑
- ✅ 添加音效
- ✅ 转场效果

## 🎨 前端生成视频方案

### 方案 A: Canvas + MediaRecorder

**适合**: 浏览器内生成视频

```javascript
// 创建 Canvas
const canvas = document.createElement('canvas');
canvas.width = 1920;
canvas.height = 1080;
const ctx = canvas.getContext('2d');

// 录制
const stream = canvas.captureStream(30);
const recorder = new MediaRecorder(stream, {
  mimeType: 'video/webm'
});

const chunks = [];
recorder.ondataavailable = e => chunks.push(e.data);
recorder.onstop = () => {
  const blob = new Blob(chunks, { type: 'video/webm' });
  const url = URL.createObjectURL(blob);
  // 下载或上传
};

recorder.start();

// 绘制动画
function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = 'pink';
  ctx.fillRect(100, 100, 200, 200);
  requestAnimationFrame(animate);
}
animate();

// 停止录制
setTimeout(() => recorder.stop(), 5000);
```

**优点**:
- ✅ 浏览器内运行
- ✅ 无需后端
- ✅ 实时生成

**缺点**:
- ⚠️ 只支持 WebM 格式
- ⚠️ 性能有限

### 方案 B: Whammy.js

**适合**: WebM 视频编码

```javascript
// 安装
npm install whammy

// 使用
const video = new Whammy.Video(30); // 30fps

// 添加帧
for (let i = 0; i < 100; i++) {
  video.add(canvas); // Canvas 元素
  video.add(canvas.toDataURL('image/webp'));
}

// 输出
const output = video.compile();
// output 是 Blob，可以下载
```

### 方案 C: ffmpeg.wasm

**适合**: 浏览器内 FFmpeg

```javascript
// 安装
npm install @ffmpeg/ffmpeg

// 使用
import { FFmpeg } from '@ffmpeg/ffmpeg';

const ffmpeg = new FFmpeg();
await ffmpeg.load();

// 写入文件
await ffmpeg.writeFile('input.png', imageData);

// 执行命令
await ffmpeg.exec([
  '-i', 'input.png',
  '-c:v', 'libx264',
  'output.mp4'
]);

// 读取结果
const data = await ffmpeg.readFile('output.mp4');
```

**优点**:
- ✅ 浏览器内运行
- ✅ FFmpeg 完整功能
- ✅ 无需后端

**缺点**:
- ⚠️ 体积大 (20MB+)
- ⚠️ 性能较慢
