## 🔓 权限配置尝试（失败经验）

### 错误配置
```json
"exec": {
  "approval": {
    "mode": "off"
  }
}
```

**错误信息**:
```
<root>: Unrecognized key: "exec"
```

**教训**: OpenClaw 2026.3.31 不支持 `exec` 配置键，需要查官方文档找正确的配置方式

### 可能的正确配置位置
1. `tools.approval.mode`
2. `security.approval.mode`
3. `commands.approval.mode`

## 💡 灵儿的学习心得

1. **配置前先查官方文档** - 不要假设配置键名
2. **PowerShell 变量不跨命令保留** - 需要合并成脚本执行
3. **硬件升级要先验证通道** - 不是所有问题都是硬件故障
4. **本地模型部署要考虑显存/内存分配** - GPU+CPU 混合运行可行
