## 🎯 自动沉淀规则

| 触发条件 | 行动 |
|---------|------|
| 同一问题问 3 次 | 标记为高频问题，存入模式层 |
| 用户纠正回答 | 记录纠正，下次使用纠正后的回答 |
| 用户满意反馈 | 强化该回答模式 |
| 用户不满意反馈 | 调整回答策略 |
