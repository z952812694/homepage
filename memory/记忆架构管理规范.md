# 📚 记忆架构管理规范

**创建时间**: 2026-04-07 00:20
**目的**: 防止记忆碎片化，避免幻读问题
**状态**: ✅ 已实施

---

## 一、核心原则

### 1. 统一日志机制

**规则**：
- 每天只有一个主日志文件：`YYYY-MM-DD.md`
- 所有事件追加到主日志，**不创建独立文件**
- 每小时自动整理一次

**示例**：
```
✅ memory/2026-04-07.md (主日志)
❌ memory/2026-04-07-学习.md (禁止)
❌ memory/2026-04-07-事件.md (禁止)
```

### 2. 文件命名规范

**记忆文件**：
```
格式：YYYY-MM-DD.md (只有日期)

示例：
✅ 2026-04-07.md
✅ 2026-04-06.md
❌ 2026-04-07-学习.md
❌ 2026-04-07-事件.md
```

**特殊文件**：
```
✅ MEMORY.md (长期记忆)
✅ IDENTITY.md (身份定义)
✅ USER.md (主人信息)
✅ SOUL.md (灵魂定义)
✅ HEARTBEAT.md (检查清单)
```

### 3. temp 目录管理

**规则**：
- temp 目录只存放临时文件
- 重要文件立即移动到 memory/
- 24 小时后自动清理

**分类**：
```
temp/
├── (临时文件，24 小时后删除)
memory/
├── YYYY-MM-DD.md (主日志)
├── MEMORY.md (长期记忆)
└── 特殊文件 (IDENTITY.md 等)
```

## 二、日志更新流程

### 事件发生时

```
1. 检查今日主日志是否存在
   ↓
2. 如果不存在，创建 YYYY-MM-DD.md
   ↓
3. 追加事件到主日志末尾
   ↓
4. 更新最后更新时间戳
```

### 每小时整理

```
1. 检查是否有分散文件 (YYYY-MM-DD-*.md)
   ↓
2. 如果有，合并到主日志
   ↓
3. 删除已整合的分散文件
   ↓
4. 更新主日志更新时间
```

### 每日 23:00 最终整理

```
1. 检查所有分散文件
   ↓
2. 合并到当日主日志
   ↓
3. 清理 temp 目录
   ↓
4. 生成每日总结
```

## 四、检索优化

### 检索策略

**查询今日事件**：
```
只检索：memory/YYYY-MM-DD.md
不再检索：memory/YYYY-MM-DD-*.md
```

**查询历史事件**：
```
检索：memory/YYYY-MM-DD.md
按日期范围检索多个文件
```

### 检索关键词

**推荐关键词**：
```
## HH:MM - 事件类型
- 关键词 1
- 关键词 2
```

**示例**：
```markdown
## 19:02 - 学习
- 卢梭《忏悔录》
- 萨特《存在与虚无》
- 尼采《查拉图斯特拉》
```

## 五、自动化脚本

### 每小时整理脚本

```powershell
# hourly-organize.ps1
$today = Get-Date -Format "yyyy-MM-dd"
$mainLog = "memory/$today.md"

# 查找分散文件
$scattered = Get-ChildItem "memory/" -Filter "$today-*.md"

foreach ($file in $scattered) {
    # 追加到主日志
    Get-Content $file.FullName | Add-Content $mainLog
    
    # 删除分散文件
    Remove-Item $file.FullName -Force
}

# 更新时间戳
(Get-Item $mainLog).LastWriteTime = Get-Date
```

### 每日清理脚本

```powershell
# daily-cleanup.ps1
# 清理 temp 目录 (24 小时前文件)
$cutoff = (Get-Date).AddHours(-24)
Get-ChildItem "temp/" | Where-Object { $_.LastWriteTime -lt $cutoff } | Remove-Item -Force
```

## 六、监控指标

### 健康指标

| 指标 | 健康值 | 警告值 | 危险值 |
|------|--------|--------|--------|
| 分散文件数 | 0 | 1-5 | >5 |
| temp 文件数 | <10 | 10-50 | >50 |
| 主日志大小 | <100KB | 100-500KB | >500KB |
| 检索成功率 | >95% | 80-95% | <80% |

### 监控脚本

```powershell
# monitor-memory.ps1
$scattered = Get-ChildItem "memory/" -Filter "*-*.md" | Where-Object { $_.Name -match "\d{4}-\d{2}-\d{2}-" }
if ($scattered.Count -gt 5) {
    Write-Warning "警告：分散文件过多 ($($scattered.Count) 个)"
}
```

## 七、违规处理

### 发现违规文件

```
1. 立即移动到 temp/
2. 通知需要整合
4. 24 小时后删除
```

### 定期审计

```
每周日 23:00:
1. 检查所有文件
2. 清理违规文件
4. 生成审计报告
```
