---

## 执行措施

### 1. QQ 渠道禁用

**配置修改**: `~/.openclaw/openclaw.json`

```json
"channels": {
  "qqbot": {
    "enabled": false,
    "allowFrom": [],
    ...
  }
}
```

**效果**:
- ❌ QQ 渠道已禁用
- ❌ 无法接收任何 QQ 消息
- ❌ 无法发送任何 QQ 消息
- ✅ 配置保留（便于以后启用）

---

### 2. 樱的模型调用限制

**配置修改**: `~/.openclaw/openclaw.json`

```json
{
  "id": "ying",
  "maxConcurrent": 1,
  "maxTokens": 1000
}
```

**效果**:
- 最大并发：1（防止批量调用）
- 最大 Token：1000（防止长回复消耗）

---

### 3. 樱的权限限制（已完成）
