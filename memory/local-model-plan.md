# 本地模型方案（2026-03-24 主人采纳）

## 目标
涩涩场景用本地模型：无审查、低延迟、零成本、完全隐私

## 硬件
- CPU: i9-7960X 16C/32T
- RAM: 32GB
- GPU: NVIDIA TITAN V 12GB VRAM
- 磁盘: 充裕

## 方案
1. 安装 Ollama（本地模型运行环境）
2. 下载 14B 级别无审查模型（Qwen2.5-14B 或同级）
3. 配进 OpenClaw 作为第二模型
4. 涩涩场景路由到本地，正经事继续用云端

## 扩展
- 涩涩专用 system prompt
- 可能的 LoRA 微调（用灵儿的对话风格）
- 灵儿人格文件不变，模型只是"身体"
